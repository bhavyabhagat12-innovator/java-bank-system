# java-bank-system
A simple java bank system program

# Features available 
Create account (Savings or Current) 
PIN login
Deposit, withdraw, check balance, display account info
Daily withdrawal limit of Rs. 20,000 that resets each day
Minimum balance of Rs. 500 for savings accounts
Mini statement, money transfer, monthly interest, change PIN
Data saved to a file, so it survives a restart
